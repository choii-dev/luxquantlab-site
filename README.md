# Lux Quant Lab

The website for Lux Quant Lab, an independent research lab focused on
quantitative trading, market behavior, strategy testing, and related projects.

## Project files

- `index.html` — homepage content, navigation, contact form, and client-side interactions.
- `research.html` — quantitative trading research page with monthly trading data.
- `style.css` — responsive layout, visual styles, and theme colors.

## Preview locally

No build step or package installation is required. Open `index.html` in a browser,
or serve the project directory with any static file server.

## Contact form

The contact form does not submit data to a website backend. Submitting it opens
the visitor's default email application with the recipient, subject, and message
filled in. The visitor must send the email from that application.

## External assets

The page loads the Inter font from Google Fonts and icons from Lucide's CDN.
